# 🏥 Hospital Appointment System (n8n Automation)

## 📌 Project Overview
This project automates hospital appointment booking using n8n.

## ⚙️ Workflow
Google Form → Google Sheets → n8n → Email Notification

## 🚀 Features
- Automated appointment scheduling
- Doctor assignment based on department
- Email confirmation to patients
- Reduces manual effort

## 🛠️ Tech Stack
- n8n
- Google Forms
- Google Sheets
- Gmail API

## 📂 Files
- hospital-appointment-workflow.json

## 🧪 How to Use
1. Import JSON into n8n
2. Connect Google Sheets & Gmail
3. Run workflow

- Add time slot booking
- WhatsApp notifications
- Doctor dashboard
